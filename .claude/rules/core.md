# 계산 로직 규칙
- `src/core`에서는 DOM, 전역 상태, 실제 네트워크를 쓰지 않는다. fetch는 인자로 주입받는다.
- 정본 규칙:
  - FUTURES·MARGIN의 손익·수수료·이자는 Bill이 정본이다.
  - SPOT 손익은 Fill로 평균단가법 계산하고, Bill은 잔고 대사에만 쓴다.
  - 다른 데이터셋의 PNL·Fee를 합산하지 않는다.
- 주문은 체결이 아니다. 취소 주문은 거래가 아니며, 부분체결을 반영한다.
- 포지션 수량은 Bill의 subType(진입·청산 방향)과 `sz`로 부호를 붙여 누적한다. `posBal`은 의미가 확인되기 전까지 수량으로 쓰지 않는다. 분류되지 않은 subType은 UNKNOWN 목록으로 반환한다.
- 통화가 다른 금액(USDT 손익과 BTC 손익 등)은 그냥 더하지 않는다. 통화별로 합계를 내고, USD 합계는 환산 기준을 note에 적는다.
- 시간은 내부에서 UTC 밀리초로 다룬다. KST 변환은 화면에서만 한다.
- 지표 함수는 `{ value, source, note }`를 반환한다. 근거가 부족하면 `null`과 사유를 반환한다.
- 모듈 하나에 테스트 파일 하나를 둔다. fixture는 합성 데이터만 쓰고, 실데이터 경로를 테스트에 넣지 않는다.
- `scripts/`의 출력은 건수와 집계만 낸다. 개별 행이나 키 값을 출력하지 않는다.
